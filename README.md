# Дипломный проект. Часть 2 — API-тесты для Stellar Burgers

## 📝 Описание проекта
Проект содержит автоматизированные API-тесты для сервиса [Stellar Burgers](https://stellarburgers.education-services.ru/). Тесты покрывают основной функционал работы с пользователями и заказами.

| JUnit          | 4.13.2   |
| Maven          | 3.9.9    |

| Lombok         | 1.18.24  |

| AspectJ        | 1.9.19   |

## ✅ Функциональность, покрытая тестами

### Тесты для пользователей (`UserApiTest`)
*   Создание уникального пользователя
*   Создание дублирующегося пользователя (ошибка)
*   Создание пользователя без обязательных полей (email, password, name)
*   Логин существующего пользователя
*   Логин с неверными учетными данными

### Тесты для заказов (`OrderApiTest`)
*   Создание заказа с авторизацией
*   Создание заказа без авторизации
*   Создание заказа без ингредиентов (ошибка)
*   Создание заказа с невалидным хешем ингредиента (ошибка 500)
*   Создание заказа с одним ингредиентом
